# Contributing to TkSharp

Thank you for your interest in contributing to TkSharp.

For questions or discussion before opening a pull request, please join the [Discord](https://tkmm.org/discord).

## Scope

TkSharp handles building changelogs for mods, merging, reading game dumps, and GameBanana API calls.

File parsing and serializing logic are out of scope for TkSharp. That work should live in external libraries and be abstracted behind interfaces.

Any user facing element (front-end / UI) belongs in [TKMM](https://github.com/TKMM-Team/Tkmm).

Please submit your contributions in the correct repository.

## Guidelines

You are expected to understand every line of code you submit, keep changes focused and reviewable, and only contribute code that you would be comfortable maintaining yourself.

Any use of AI when preparing a contribution **must be disclosed** in the pull request description.

## AI-assisted contributions

Pull requests that appear to be written entirely (or mostly) by AI or are otherwise "vibe-coded" **will be closed without review**.

AI is **not** a substitute for human programming. We will close pull requests when:

- The code looks AI-generated (generic structure, heavy diffs, unexplained complexity)
- The authors cannot explain or defend the changes they submitted
- A single feature arrives as thousands of lines of over-engineered code
